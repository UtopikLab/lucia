# LUCIA Workspace Handoff

This is the former LUCIA development workspace. Active project development has
moved to the Oli-OS repositories:

- [olios-core](https://github.com/Oli-OS/olios-core) — Rust core workspace and
  foundational crates.
- [olios-desktop](https://github.com/Oli-OS/olios-desktop) — experimental
  desktop prototypes; not a finished production shell.
- [olios-apps](https://github.com/Oli-OS/olios-apps) — app repository, currently
  README-only.

The project is in early development. This workspace remains as the former
LUCIA development home; no archival or package-renaming status is implied.
